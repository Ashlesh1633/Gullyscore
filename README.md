# Cricket Tournament Management and Live Scoring System V3 Colorful

Advanced CricHeroes-style mini web app using Python Flask + SQLite.

## Added Features
- Attractive colorful UI
- Gradient dashboard
- Modern buttons
- Colorful scorecards
- Better tables and badges

- Login system
- Admin dashboard
- Team management
- Player management
- Match creation
- Toss winner
- Batting team selection
- Two innings scoring
- Batsman and bowler selection
- Ball-by-ball scoring
- Extras: Wide, No Ball, Bye, Leg Bye
- Wicket tracking
- Auto overs calculation
- Auto target calculation
- Auto match result
- Player batting stats
- Player bowling stats
- Scorecard
- Commentary
- Points table
- Modern UI
